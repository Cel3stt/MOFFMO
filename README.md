# 💬 MOFFMO — Real-Time Chat Application

A sleek, real-time chat application built with the **MERN stack**, powered by **Socket.io** for instant messaging and **DaisyUI** for beautiful, themeable UI components. ✨

> 📁 Repo: `MOFFMO`  
> 🛠️ Tech Stack: MongoDB • Express • React • Node.js • Socket.io • DaisyUI  
> 🎨 Themeable • Responsive • Realtime Messaging

---

## 🚀 Features

- 💬 Real-time 1:1 messaging via **Socket.io**
- 🧑‍🤝‍🧑 User authentication and session management
- 🎨 **DaisyUI themes** – customizable light/dark/soft themes
- 🖥️ Responsive design across devices
- 📡 Backend API with **Express + MongoDB**
- 🔐 Basic auth setup (JWT/session-based or token fallback)

---

## 🌐 Technologies Used

| Tech           | Role                       |
|----------------|----------------------------|
| **React.js**   | Frontend UI (w/ DaisyUI)   |
| **Node.js**    | Backend runtime            |
| **Express.js** | API & server framework     |
| **MongoDB**    | NoSQL Database             |
| **Socket.io**  | Real-time communication    |
| **DaisyUI**    | Tailwind-based UI library  |
